Shortcuts & Tips

      
    

    

      

        
Compilation

        
Ctrl+EnterF5Compile / Recompile

        
Ctrl+SSave current file

        
Right-click a .tex file in the tree → "Set as main file" before compiling a multi-file project.

      

      

        
SyncTeX — Editor ↔ PDF

        
Alt+Clickin editor → jump to PDF page (forward)

        
Ctrl+Alt+FForward sync shortcut

        
Clickon PDF → jump to source line (inverse)

        
SyncTeX requires at least one successful compile first.
